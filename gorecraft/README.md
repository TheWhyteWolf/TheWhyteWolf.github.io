# Crimson Codex and The Keep

Production assets for `v16-crimson.html` and `v17-keep.html`. The renderer reads
the existing `data.js`, and both pages use the shared intro and demo engines.

The title illustration is copied unchanged from Gorecraft’s
`build/art-choices/images/title_art.jpg` in `/home/whyte/git/Trpt`. The Keep’s
isometric rooms are drawn on canvas and quantized to four exact inks from the
Architect facet: `#000000`, `#012429`, `#13d5ec`, and `#cef7fe`.

The IBM VGA font is from VileR’s Ultimate Oldschool PC Font Pack, copied
unchanged from Gorecraft. Its CC BY-SA 4.0 licence is included in
`assets/Px437-LICENSE.txt`.
