NAME

allthemalware — the archive of Whyte Erminae

SYNOPSIS

allthemalware

DESCRIPTION

Projects and experiments — web apps for the tabletop, ASCII art that moves, audio and chiptune software, a Linux desktop grown out of Conway's Game of Life, and command-line software for archiving and converting things in bulk.

Each entry is marked live if it runs in your browser, src if it is a source repository, or wip if it is still under construction. Entries indented beneath another are parts of it, not separate programs.

AUTHOR

Written by Whyte Erminae.
